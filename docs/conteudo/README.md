## Convenção

Todo texto abaixo é **genérico de propósito** — o protótipo avisa isso ao abrir. Nomes de
casais, depoimentos, datas e valores são fictícios e devem continuar marcados como exemplo
onde o protótipo já marcava. O conteúdo real entra depois, pelo painel.
